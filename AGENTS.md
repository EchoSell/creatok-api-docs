# Documentation project instructions

## About this project

- Public developer docs for the CreatOK API, built on [Mintlify](https://mintlify.com)
- Pages are MDX files with YAML frontmatter; configuration lives in `docs.json`
- The source of truth for API behavior is the CreatOK app repository (`app/api/v1/**`, `lib/api-platform/**`). Never document behavior that the code does not implement.
- `api-reference/openapi.json` is generated by the app. Refresh it instead of editing it by hand (see `README.md`).

## Terminology

- "workspace" for the customer account that owns keys, jobs, and the API wallet
- "organization API key" for `cok_` keys; never call personal `ok_` keys API keys
- "job" for the asynchronous resource returned by generation endpoints
- Use public model IDs (`seedance-2-mini`), never provider model names (`doubao-seedance-2-mini`)

## Style preferences

- English only, active voice, second person ("you")
- Keep sentences concise — one idea per sentence
- Sentence case for headings
- Bold for UI elements: Click **API Keys**
- Code formatting for fields, headers, endpoints, and error codes

## Content boundaries

- Do not document internal routes (`/api/internal/**`), worker callbacks, admin top-up tools, providers, or margins
- Do not document endpoints that are not usable end to end
- Never write per-second rates or example totals; link to https://www.creatok.ai/app/api-platform/pricing
