Select a public model ID with the `model` field of `POST /videos/generation`. The Seedance and Veo families have different inputs and limits. All models support text prompts and first/end frames. Seedance models support reference videos and audio. Veo models do not support reference videos or audio; only some variants accept reference images.

## Models

| Model | Resolutions | Duration (seconds) |
| --- | --- | --- |
| `seedance-2.5` | `480p`, `720p`, `1080p` | 4–30 |
| `seedance-2` | `480p`, `720p`, `1080p`, `4k` | 4–15 |
| `seedance-2-fast` | `480p`, `720p` | 4–15 |
| `seedance-2-mini` | `480p`, `720p` | 4–15 |

## Veo 3.1 models

All Veo variants currently generate 8-second videos. They support `720p` or `1080p`; `veo-3.1-lite-exp` also supports `4k`. Their supported orientations are `9:16` and `16:9`, with `9:16` as the default.

| Variant | `model` | Resolutions | Reference images |
| --- | --- | --- | --- |
| Veo 3.1 Lite | `veo-3.1-lite-exp` | `720p`, `1080p`, `4k` | Not supported |
| Veo 3.1 (Exp) | `veo-3.1-exp` | `720p`, `1080p` | Not supported |
| Veo 3.1 Fast (Exp) | `veo-3.1-fast-exp` | `720p`, `1080p` | Up to 3 |
| Veo 3.1 | `veo-3.1` | `720p`, `1080p` | Up to 3 |
| Veo 3.1 Fast | `veo-3.1-fast` | `720p`, `1080p` | Up to 3 |

See the [Veo 3.1 generation guide](/models/video/veo-3.1/generation) for request examples and variant-specific inputs.

## Input fields

The field table below describes the shared request shape. Accepted values depend on the model. Use the model tables above and the Seedance or [Veo guide](/models/video/veo-3.1/generation) for the supported choices.

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `prompt` | string | — | **Required.** What the video shows. |
| `seconds` | integer | Model default | Seedance accepts model-specific ranges. Veo variants currently support only `8`. Omit in Seedance 2.5 edit mode. |
| `definition` | string | Model default | Output resolution supported by the selected model. Veo defaults to `720p`. |
| `orientation` | string | Model default | Seedance accepts `21:9`, `16:9`, `4:3`, `1:1`, `3:4`, `9:16`, or `auto`. Veo accepts `16:9` or `9:16`. Omit in Seedance 2.5 frame and edit modes. |
| `watermark` | boolean | — | Whether to add a watermark. |
| `seed` | string | — | Seed for more repeatable results. |
| `referenceImageKeys` | string[] | — | Seedance accepts uploaded reference images. Veo accepts up to 3 only for `veo-3.1`, `veo-3.1-fast`, and `veo-3.1-fast-exp`. [Upload first](/guides/files), then use the returned `file_id`. |
| `referenceVideoKeys` | string[] | — | Seedance only. [Upload first](/guides/files), then use the returned `file_id`. |
| `referenceAudioKeys` | string[] | — | Seedance only. Limits and visual-reference requirements vary by Seedance model. [Upload first](/guides/files#upload-reference-audio), then use the returned `file_id`. |
| `firstFrameKey` | string | — | First-frame image; required in frame mode. [Upload first](/guides/files), then use the returned `file_id`. |
| `endFrameKey` | string | — | Optional end-frame image; requires a first frame. [Upload first](/guides/files), then use the returned `file_id`. |
| `generationMode` | string | inferred | `reference` or `frame` for Veo. Seedance 2.5 also supports `edit`. |
| `autoMatchVideoDuration` | boolean | `true` in edit mode | Only supported for Seedance 2.5 edit mode. |

Media fields accept the `file_id` or `upload_fields.key` from [Files](/guides/files), after upload completes. They do not accept arbitrary URLs or files from another workspace. Prompts are limited to 8,000 characters.

Unknown fields at the request root or inside `input` return `400 invalid_parameter`. Set `seconds` and `definition` explicitly when you need a specific duration or resolution.

```json
{
  "model": "seedance-2.5",
  "input": {
    "prompt": "A product shot of a ceramic mug rotating on a marble table",
    "seconds": 8,
    "definition": "720p",
    "orientation": "9:16"
  },
  "max_cost_usd": "2.00"
}
```

## Media modes

Upload each asset first. Replace the sample file IDs below with your own completed uploads.

- Reference images/videos select `reference` automatically when `generationMode` is omitted. On Seedance 2, Fast, and Mini, reference audio requires at least one reference image or video in the same request; audio alone is rejected. Seedance 2.5 accepts audio-only reference requests. Audio limits differ per model — see the field table above.
- `firstFrameKey` selects `frame` automatically. You cannot combine frames with reference images, videos, or audio or a different mode.
- Set `generationMode: "edit"` explicitly for Seedance 2.5 editing. At least one reference video is required. Omit `seconds` and `orientation`; the first source video determines output duration and aspect ratio. `autoMatchVideoDuration` defaults to `true`; `false` is rejected. Output duration is not guaranteed to be frame-exact.

```json Reference image
{
  "model": "seedance-2-mini",
  "input": {
    "prompt": "Animate this product with a slow camera orbit",
    "referenceImageKeys": ["file_11111111-1111-4111-8111-111111111111"]
  }
}
```

```json Reference video
{
  "model": "seedance-2-mini",
  "input": {
    "prompt": "Use the reference camera movement for a beach scene",
    "referenceVideoKeys": ["file_22222222-2222-4222-8222-222222222222"],
    "seconds": 4
  }
}
```

```json Multiple images and mixed references
{
  "model": "seedance-2-mini",
  "input": {
    "prompt": "Combine these product views using the reference camera movement",
    "referenceImageKeys": [
      "file_11111111-1111-4111-8111-111111111111",
      "file_33333333-3333-4333-8333-333333333333"
    ],
    "referenceVideoKeys": ["file_22222222-2222-4222-8222-222222222222"],
    "seconds": 4
  }
}
```

For multiple images without video, omit `referenceVideoKeys` from this example.

```json First and last frames
{
  "model": "seedance-2-mini",
  "input": {
    "prompt": "Transition smoothly between these frames",
    "generationMode": "frame",
    "firstFrameKey": "file_11111111-1111-4111-8111-111111111111",
    "endFrameKey": "file_33333333-3333-4333-8333-333333333333"
  }
}
```

```json Adaptive editing
{
  "model": "seedance-2.5",
  "input": {
    "prompt": "Replace the background with a beach",
    "generationMode": "edit",
    "referenceVideoKeys": ["file_22222222-2222-4222-8222-222222222222"],
    "autoMatchVideoDuration": true
  }
}
```

For Seedance 2 family image/audio and mixed image/video/audio requests, see the [audio examples](/models/video/seedance-2/generation#reference-audio).

## Seedance media limits

The limits in this section apply to Seedance. The upload limit and model limit both apply. Images are capped at **10 MiB** by the upload grant, including for Seedance 2.5. Videos are capped at **100 MiB** by the upload grant, and **50 MiB** for Seedance 2 / Mini / Fast at generation submission. Veo image inputs use the same 10 MiB upload limit; see the [Veo guide](/models/video/veo-3.1/generation) for its model-specific image support.

| Constraint | Seedance 2 / Mini / Fast | Seedance 2.5 |
| --- | --- | --- |
| Reference images | Up to 9 | Up to 30 |
| Reference videos | Up to 3 | Up to 10 |
| Reference audio | Up to 3; 2–15 seconds each, 15 seconds total; requires an image or video | Up to 10; 2–30 seconds each, 30 seconds total |
| Combined reference items | At most 15 across images, videos, and audio | At most 50 across images, videos, and audio |
| Video duration | 2–15 seconds each, at most 15 seconds total | 2–30 seconds each, at most 30 seconds total; edit requires at least 4 seconds |
| Video dimensions | 300–6000 pixels per side; 409,600–927,408 total pixels | 300–6000 pixels per side; 409,600–8,295,044 total pixels |
| Video frame rate | 23–60 fps | 23–60 fps |

Reference audio accepts WAV or MP3. The upload grant allows up to 100 MiB per file, but the models enforce a stricter **15 MiB** limit per audio file at submission, alongside the duration limits above.

Images must be 300–6000 pixels per side. Images and videos must have an aspect ratio between 0.4 and 2.5. Videos use MP4 or MOV. Images use JPEG, PNG, or WebP; Seedance 2.5 also accepts BMP, TIFF, GIF, HEIC, and HEIF. The server validates actual media metadata before charging; an upload grant alone does not guarantee the model can use the file.

## Pricing

The details below describe Seedance pricing. Veo pricing depends on the selected variant and resolution; see the [Veo guide](/models/video/veo-3.1/generation#pricing) and [pricing page](https://www.creatok.ai/app/api-platform/pricing).

You pay for estimated token usage, using the model's USD unit price per million tokens:

**Cost = estimated tokens × USD price per million tokens / 1,000,000**

The final charge rounds up to one micro-dollar (six decimal places). Dimensions, aspect ratio, and billable duration determine token usage. With reference video, billable duration is output duration plus the greater of four seconds or total reference-video duration. Without reference video, only output duration contributes.

Text and image inputs use the same unit-price category. Reference-video inputs use a separate category. Some models have separate high-resolution price tiers; 480p and 720p share a tier. In edit mode the server resolves duration and aspect ratio from the source video before quoting. Workspace contract pricing applies when configured.

See current rates on the [pricing page](https://www.creatok.ai/app/api-platform/pricing) in the API console. Each job keeps the rate that applied when it was accepted, and `cost.amount_usd` on the job shows the exact charge.

## Capping the cost

Set `max_cost_usd` to the most you are willing to pay for a job, as a decimal string with up to six decimal places. If the job would cost more, the request fails with `400 max_cost_exceeded` and you are not charged. This protects you from unexpected charges if prices change.
