## Base URL

```text
https://api.creatok.ai/v1
```

## Authentication

Send your organization API key as a bearer token. See [Authentication](/guides/authentication).

```bash
Authorization: Bearer cok_...
```

## Conventions

- API requests and responses use JSON. The separate signed file upload uses multipart form data.
- Successful responses return the resource directly with a `2xx` status. Errors use the [error format](/guides/errors).
- Every response includes an `X-Request-Id` header.
- Money amounts are decimal USD strings, with six decimal places.
- Generation and cleaning timestamps are ISO 8601 strings in UTC. Publishing task timestamps and `schedule.at` use Unix milliseconds.

## OpenAPI specification

The machine-readable specification is available without authentication:

```text
https://api.creatok.ai/v1/openapi.json
```
