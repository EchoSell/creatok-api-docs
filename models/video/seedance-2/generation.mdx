Use the Seedance 2 family with `POST https://api.creatok.ai/v1/videos/generation`. Choose a model variant, select a scenario below, then submit its request body and poll the returned job.

## Choose a model

| Variant | `model` | Resolutions | Output duration |
| --- | --- | --- | --- |
| Seedance 2 | `seedance-2` | `480p`, `720p`, `1080p`, `4k` | 4–15 seconds |
| Seedance 2 Fast | `seedance-2-fast` | `480p`, `720p` | 4–15 seconds |
| Seedance 2 Mini | `seedance-2-mini` | `480p`, `720p` | 4–15 seconds |

All three variants share the input fields, media modes, and media limits on this page. The examples use `seedance-2` at `480p`. To use Fast or Mini, replace only the root `model` value with the corresponding ID. Keep `definition` at `480p` or `720p` for those variants.

[Seedance 2.5](/models/video/seedance-2.5/generation) has its own limits and supports adaptive editing.

## Supported scenarios

| Scenario | Input fields | Mode |
| --- | --- | --- |
| [Text to video](#text-to-video) | `prompt` | Omit `generationMode` |
| [Single reference image](#single-reference-image) | `prompt`, `referenceImageKeys` | `reference` |
| [Multiple reference images](#multiple-reference-images) | `prompt`, `referenceImageKeys` | `reference` |
| [Reference video](#reference-video) | `prompt`, `referenceVideoKeys` | `reference` |
| [Images and video together](#images-and-video-together) | `prompt`, both reference arrays | `reference` |
| [Reference image and audio](#reference-audio) | `prompt`, `referenceImageKeys`, `referenceAudioKeys` | `reference` |
| [Images, video, and audio](#images-video-and-audio) | `prompt`, both reference arrays, `referenceAudioKeys` | `reference` |
| [First frame](#first-frame) | `prompt`, `firstFrameKey` | `frame` |
| [First and last frames](#first-and-last-frames) | `prompt`, `firstFrameKey`, `endFrameKey` | `frame` |

For adaptive editing, use [Seedance 2.5](/models/video/seedance-2.5/generation#adaptive-video-editing). These three variants do not accept `generationMode: "edit"`.

## Before you start

Create an [organization API key](/guides/authentication) and fund your API wallet. For images, videos, or audio, complete the [signed upload flow](/guides/files) first. Replace each example `file_...` value with the returned `file_id`. You can also use the returned `upload_fields.key`.

<Note>
  These examples use the CreatOK request format. Put generation parameters inside `input`. Media fields accept uploaded file identifiers, not public URLs, base64 strings, or `asset://` identifiers. A prompt is required in every mode.
</Note>

## Parameters

At the request root, supply `model` and `input`. You can also set `metadata` to a JSON object and `max_cost_usd` to a nonnegative decimal string with up to six decimal places. The cost cap is a spending limit, not a quoted price.

Use these fields inside `input`:

| Field | Type | Rules |
| --- | --- | --- |
| `prompt` | string | Required, nonempty after trimming; at most 8,000 characters. |
| `seconds` | integer | 4–15; defaults to `4`. |
| `definition` | string | Defaults to `480p`. Use a resolution supported by your variant in the table above. |
| `orientation` | string | `21:9`, `16:9`, `4:3`, `1:1`, `3:4`, `9:16`, or `auto`. Defaults to `9:16` for text/reference modes. You can also set this in frame mode. |
| `referenceImageKeys` | string[] | Up to 9 uploaded images. [Upload first](/guides/files), then use the returned `file_id`. |
| `referenceVideoKeys` | string[] | Up to 3 uploaded videos. [Upload first](/guides/files), then use the returned `file_id`. |
| `referenceAudioKeys` | string[] | Up to 3 uploaded audio files, 2–15 seconds each and at most 15 seconds total, 15 MiB per file, WAV or MP3. Requires at least one reference image or video. [Upload first](/guides/files#upload-reference-audio), then use the returned `file_id`. Cannot be combined with frames. |
| `firstFrameKey` | string | An uploaded image; required in frame mode. [Upload first](/guides/files), then use the returned `file_id`. |
| `endFrameKey` | string | An uploaded image; requires `firstFrameKey`. [Upload first](/guides/files), then use the returned `file_id`. |
| `generationMode` | string | `reference` or `frame`. Reference/frame mode is inferred from the media fields when omitted. |
| `autoMatchVideoDuration` | boolean | Omit this field. `true` is not accepted by these variants. |
| `watermark` | boolean | Optional watermark setting. |
| `seed` | string | Optional seed, for example `"42"`; do not send a JSON number. Results are not guaranteed to be identical. |

Unknown fields are rejected with `400 invalid_parameter`. The API does not accept `duration`, `resolution`, `size`, `image_urls`, `video_urls`, `audio_urls`, `generate_audio`, or `return_last_frame`. Use the fields documented above.

## Media requirements

| Constraint | Limit |
| --- | --- |
| Reference audio | Up to 3 files, 2–15 seconds each, at most 15 seconds total, 15 MiB per file, WAV or MP3 |
| Image size | 10 MiB per upload |
| Image formats | JPEG, PNG, WebP |
| Image dimensions | 300–6000 pixels per side |
| Video size | 50 MiB per file |
| Video formats | MP4 or MOV |
| Video duration | 2–15 seconds per video, at most 15 seconds total |
| Video dimensions | 300–6000 pixels per side; 409,600–927,408 total pixels |
| Video frame rate | 23–60 fps |
| Image and video aspect ratio | 0.4–2.5 |

You can combine up to 9 images, 3 videos, and 3 audio files, with at most 15 reference items in total.

The server checks uploaded media before charging. A successful upload does not guarantee that a file meets the model's requirements. Frame images follow the same image restrictions as reference images.

## Submit a request

Save one complete JSON example below as `request.json`. Set your key and generate an idempotency key once for that request:

```bash
export CREATOK_API_KEY="cok_..."
export CREATOK_IDEMPOTENCY_KEY="$(uuidgen)"
```

Submit the file:

```bash
curl --fail-with-body --include https://api.creatok.ai/v1/videos/generation \
  -H "Authorization: Bearer $CREATOK_API_KEY" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: $CREATOK_IDEMPOTENCY_KEY" \
  --data-binary @request.json
```

Keep the same key and body when retrying a network failure or server error. Generate a new key when you switch examples or change any request field. See [Idempotency](/guides/idempotency).

## Text to video

Describe the scene, subject movement, and camera movement. No upload is required.

```json
{
  "model": "seedance-2",
  "input": {
    "prompt": "A paper lantern floats above a still lake at dusk, slow tracking shot",
    "seconds": 4,
    "definition": "480p",
    "orientation": "16:9"
  }
}
```

## Reference audio

<Note>
  [Upload each reference file first](/guides/files). For audio, use its actual MIME type, such as `audio/mpeg` for MP3. Complete the multipart upload, then replace the sample IDs with the returned `file_id` values. `upload_fields.key` is also accepted.
</Note>

Seedance 2, Fast, and Mini accept up to 3 reference audio files, 2–15 seconds each and at most 15 seconds in total, 15 MiB per file, WAV or MP3. At least one reference image or video is required when you provide `referenceAudioKeys`; audio alone is rejected before generation. A prompt is also required. These rules apply to the Seedance 2 family; check each model's guide for its own input requirements.

```json
{
  "model": "seedance-2",

    "prompt": "Show the dancer from the reference image moving in time with the reference audio",
    "referenceImageKeys": [
      "file_11111111-1111-4111-8111-111111111111"
    ],
    "referenceAudioKeys": [
      "file_44444444-4444-4444-8444-444444444444"
    ],
    "seconds": 4,
    "definition": "480p",
    "orientation": "16:9"
  }
}
```

## Read the result

HTTP `202` returns a job directly. Read its `id` and `status`; there is no `data` wrapper. A submission can already have `status: "failed"`, so do not treat `202` as generation success.

While the job is `queued` or `running`, wait the number of seconds in `Retry-After`, then retrieve it:

```bash
curl --fail-with-body --include https://api.creatok.ai/v1/jobs/JOB_ID \
  -H "Authorization: Bearer $CREATOK_API_KEY"
```

Replace `JOB_ID` with the returned `id`. Continue until the status is `succeeded`, `failed`, or `canceled`. On success, download the video URL in `output.files`. URLs last about one hour; retrieve the job again for a fresh URL. Copy the output to your storage before `expires_at`, 48 hours after completion.

For a complete polling and download script, see [Quickstart](/quickstart#complete-example). See [Jobs and polling](/guides/jobs) for response fields and refunds.

## Common errors

| Result | What to check |
| --- | --- |
| `400 invalid_parameter` | Check the model's field values, uploaded files, and media limits. Do not mix frame inputs with reference images, videos, or audio. |
| `400 missing_parameter` | Supply a nonempty `Idempotency-Key` of at most 255 characters. |
| `400 max_cost_exceeded` | The quote exceeds your cost cap. Review the input or cap before resubmitting. |
| `402` | Check that your API wallet is enabled and has sufficient balance. |
| `409 idempotency_key_reused` | You changed the request while reusing a key. Use the original body for a retry or a new key for a new job. |
| `429 concurrency_limited` | Wait `Retry-After` seconds and retry with the same key and body. |
| Job `failed` | Read `error.code` and `cost.refunded_usd`. To request another generation, use a new key. |

See [Errors](/guides/errors) for all error codes. See the [pricing page](https://www.creatok.ai/app/api-platform/pricing) for current rates and [token pricing](/guides/video-models#pricing) for how media affects usage.
