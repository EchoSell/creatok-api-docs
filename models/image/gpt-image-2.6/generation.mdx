---
title: "GPT Image 2.6"
description: "Generate an image with GPT Image 2.6 Flare or Sunburst."
---

Choose the model by setting `model` in your `POST /images/generation` request.

| Model | `model` value |
| --- | --- |
| GPT Image 2.6 Flare | `gpt-image-2.6-flare` |
| GPT Image 2.6 Sunburst | `gpt-image-2.6-sunburst` |

Each job generates one image. Both models accept a prompt and up to 16 uploaded reference images, and can generate a transparent PNG.

## Create a job

Send an organization API key and a unique `Idempotency-Key`. Reuse the same key and request body when retrying the same job.

```bash
export CREATOK_IDEMPOTENCY_KEY="$(uuidgen)"
curl https://api.creatok.ai/v1/images/generation \
  -H "Authorization: Bearer $CREATOK_API_KEY" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: $CREATOK_IDEMPOTENCY_KEY" \
  -d '{
    "model": "gpt-image-2.6-flare",
    "input": {
      "prompt": "A product photograph of a ceramic mug on a clean desk",
      "resolution": "1K",
      "aspectRatio": "1:1",
      "quality": "low"
    }
  }'
```

The API returns HTTP `202` and a job. [Poll the job](/guides/jobs) using its `id`. After it succeeds, download the image from `output.files`.

## Input fields

| Field | Values | Default |
| --- | --- | --- |
| `input.prompt` | 1–5,000 Unicode code points after trimming | Required |
| `input.resolution` | `1K`, `2K`, `4K` | `1K` for fixed sizes |
| `input.aspectRatio` | `auto`, `1:1`, `3:4`, `4:3`, `9:16`, `16:9`, `21:9`, `3:2`, `2:3`, `5:4`, `4:5`, `2:1`, `1:2`, `9:21`, `3:1`, `1:3` | `1:1` for fixed sizes |
| `input.quality` | `low`, `medium`, `high`, `xhigh`, `max` | `low` |
| `input.customSize` | An object with integer `width` and `height` in pixels | Optional |
| `input.referenceImageKeys` | Up to 16 uploaded images | Empty array |
| `input.transparentBackground` | Boolean | `false` |

## Generate with reference images

[Upload each reference](/guides/files) and put its `file_id` or `upload_fields.key` in `referenceImageKeys`. Use nonempty JPG, PNG, or WebP files from your workspace, up to 10 MiB each.

```json
{
  "model": "gpt-image-2.6-sunburst",
  "input": {
    "prompt": "Place the mug from the reference image on a bright kitchen countertop",
    "resolution": "2K",
    "aspectRatio": "4:3",
    "quality": "medium",
    "referenceImageKeys": ["file_11111111-1111-4111-8111-111111111111"]
  }
}
```

## Custom size and transparency

To set exact dimensions, send `customSize` and omit `resolution` and `aspectRatio`. Each side must be a multiple of 16 and at most 3,840 px. The image must have 655,360–8,294,400 total pixels and a long-to-short side ratio of at most 3:1.

Set `transparentBackground` to `true` to get a transparent PNG. You can use it with fixed or custom dimensions and with uploaded references. The default background is opaque.

```json
{
  "model": "gpt-image-2.6-sunburst",
  "input": {
    "prompt": "A ceramic mug isolated on a transparent background",
    "customSize": { "width": 1280, "height": 1024 },
    "transparentBackground": true
  }
}
```

## Token billing

CreatOK estimates text input tokens from the prompt, image input tokens from the uploaded references, and image output tokens from the output dimensions and quality. Each reference entry contributes to the estimate, including repeated entries. For `aspectRatio: "auto"`, CreatOK uses the square dimensions at the selected resolution to estimate output tokens.

### 1024 × 1024 output token estimates

These estimates apply to one output image for either Flare or Sunburst.

| Quality | Estimated image output tokens |
| --- | ---: |
| `low` | 823 |
| `medium` | 1,449 |
| `high` | 1,756 |
| `xhigh` | 3,122 |
| `max` | 7,024 |

CreatOK applies each rate to its estimated token count, sums the charges, and rounds up to the nearest microdollar. It charges this estimate before generation. Transparent images use the same token rates. See the [API pricing page](https://www.creatok.ai/app/api-platform/pricing) for rates per million tokens.

Set the optional `max_cost_usd` field to a decimal USD string with up to six decimal places. A quote above the cap returns `400 max_cost_exceeded` before charging. Read the charge in the job's `cost.amount_usd` and any refund for a failed or canceled job in `cost.refunded_usd`.
