---
title: "Seedream 5.5"
description: "Generate one image from a prompt or uploaded reference images."
---

Use `model: "seedream-5.5"` with `POST /images/generation`. Each job generates one image from your prompt and up to 10 uploaded reference images.

## Create a job

Send an organization API key and an `Idempotency-Key`. Reuse the same key and body when retrying the same job.

```bash
export CREATOK_IDEMPOTENCY_KEY="$(uuidgen)"
curl https://api.creatok.ai/v1/images/generation \
  -H "Authorization: Bearer $CREATOK_API_KEY" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: $CREATOK_IDEMPOTENCY_KEY" \
  -d '{
    "model": "seedream-5.5",
    "input": {
      "prompt": "A product photograph of a ceramic mug on a clean desk",
      "resolution": "1K",
      "aspectRatio": "1:1"
    }
  }'
```

The API responds with HTTP `202` and a job. Poll `GET /jobs/{jobId}` and download the completed image from `output.files`. [Jobs and polling](/guides/jobs)

## Input fields

| Field | Values | Default |
| --- | --- | --- |
| `input.prompt` | 1–5,000 Unicode code points after trimming | Required |
| `input.resolution` | `1K`, `2K` | `1K` for fixed sizes |
| `input.aspectRatio` | `1:1`, `4:3`, `3:4`, `16:9`, `9:16`, `3:2`, `2:3`, `21:9` | `1:1` for fixed sizes |
| `input.referenceImageKeys` | Up to 10 uploaded images | Empty array |
| `input.customSize` | An object with positive integer `width` and `height` in pixels | Optional |
| `input.transparentBackground` | Boolean | `false` |

You can also include `metadata` and `max_cost_usd` at the request root. Unknown fields return `400 invalid_parameter`.

## Generate with reference images

Upload each image with `POST /files`, then put its `file_id` or `upload_fields.key` in `input.referenceImageKeys`. Each image must belong to your workspace, have an image content type, be nonempty, and be at most 10 MiB. Each side must be at least 15 px, with at most 36 million total pixels and a width-to-height ratio from 1:16 to 16:1. [Upload guide](/guides/files)

```json
{
  "model": "seedream-5.5",
  "input": {
    "prompt": "Place the mug in a bright kitchen",
    "referenceImageKeys": ["file_11111111-1111-4111-8111-111111111111"]
  }
}
```

## Custom size and transparency

Use `customSize` for exact dimensions and omit `resolution` and `aspectRatio`. A custom size must have 921,600–4,624,220 total pixels and a width-to-height ratio from 1:16 to 16:1.

Set `transparentBackground` to `true` for a transparent PNG. It works with fixed or custom sizes and with uploaded references. For a custom-size JPEG, omit `transparentBackground`.

```json
{
  "model": "seedream-5.5",
  "input": {
    "prompt": "A ceramic mug on a transparent background",
    "customSize": { "width": 1040, "height": 1040 },
    "transparentBackground": true
  }
}
```

## Cost and retries

You pay for one output image plus each entry in `referenceImageKeys`, including repeated references to the same image. For a custom size, total pixels are `width × height`. Fixed sizes use the tier shown below. Transparency uses the same rates.

| Item | USD per image |
| --- | ---: |
| Input reference image | $0.0069 |
| Output up to 2,610,000 pixels (fixed 1K) | $0.0178 |
| Output over 2,610,000 and up to 4,624,220 pixels (about 4.62M, fixed 2K) | $0.0315 |

Displayed rates are rounded to four decimal places. The API quotes and charges to six decimal places, so a displayed rate can be lower than the exact rate. [Current API pricing](https://www.creatok.ai/app/api-platform/pricing)

Set `max_cost_usd` to a decimal USD string with up to six decimal places to cap the charge for this job. If the exact quote exceeds your cap, the API returns `400 max_cost_exceeded` before creating the job or charging your wallet. The returned job shows the exact charge in `cost.amount_usd` and any refund in `cost.refunded_usd`.

Reuse the original idempotency key and body after a timeout. [Idempotency](/guides/idempotency)
