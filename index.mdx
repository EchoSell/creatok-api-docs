The CreatOK API lets your server generate videos with Seedance models. You submit a generation request, receive a job, and poll the job until the video is ready to download.

```text
https://api.creatok.ai/v1
```

## How it works

1. Create an organization API key in the [API console](https://www.creatok.ai/app/api-platform/api-keys).
2. Submit `POST /videos/generation` with a model, an input, and an `Idempotency-Key`.
3. Poll `GET /jobs/{jobId}` until the job reaches a final status.
4. Download the video from `output.files` within 48 hours.

Every job is charged in USD from your workspace's API wallet when it is accepted. Failed jobs are refunded automatically.
